# Checkmark Document — Cross-platform Logo Kit

Minimalist vector redraw based on the supplied checkmark-document icon.

## Included
- `vector/`: editable SVG masters (primary, mono-dark, mono-light)
- `png/`: transparent PNG logos at 16–1024 px and opaque application icons
- `web/`: favicons, web app icons and example webmanifest
- `macos/`: ICNS; `windows/`: ICO; `linux/`: PNGs
- `ios/`: opaque 1024 px app icon
- `android/`: launcher resolutions, adaptive icon XML and foreground/background assets
- `Logo-Usage-Guide.pdf`: colors and setup notes

## Notes
Android adaptive foreground is an editable starting point; apply additional inset for the intended launcher safe zone. Rename example app metadata before shipping. All artwork is newly redrawn as SVG paths.
